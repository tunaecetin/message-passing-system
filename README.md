# 📡 Message Passing System (Double Linked List)

This project simulates a message passing system between students using a Doubly Linked List.

---

## 🚀 Features

✔ Random student selection  
✔ Hub nodes (special nodes)  
✔ Message passing simulation  
✔ Direction change (left/right)  
✔ Random movement logic  

---

## 📁 Files

- Problem2.java  
- names.txt  

---

## ▶️ How to Run

1. Run Problem2.java  
2. Enter number of hubs  
3. Enter a message  
4. Watch the simulation  

---

## 🎯 System Logic

- 30 random students are selected  
- Some students become HUB nodes  
- A random student starts the process  
- Message is passed:
  - Left or right randomly  
  - Changes direction at hubs  
- Stops when all students are visited
